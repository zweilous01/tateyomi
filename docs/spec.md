# 仕様と決定事項（毎回読まなくてよい）

## できていること
- ページ制（800×1130・仮）、ページの追加・並べ替え・複製・削除、自動保存、マイギャラリー
- レイヤー：表示・ロック・不透明度・合成・複製・下と結合、用紙の色
- 右端のレイヤーの帯（開閉可）：タップで選択、長押しで並べ替え、動かさず離すと詳細、目のマークで表示切替、＋で絵レイヤー追加
- 道具：ペン（筆圧・手ぶれ補正・トーン）、消しゴム、塗りつぶし、図形、スポイト、範囲選択、移動
- 画面：2本指で拡大（最大1200%）・スクロール・ひねって回転（↻ボタンで戻す）。2本指タップ＝ひとつ戻す、3本指タップ＝やり直し。画面全体の拡大・ずれは防止
- 作品を開くと「移動」の道具から始まり、前回さわっていたページから表示（ページだけ覚える。端末の中に保存）
- 文字：7フォント、縦書き、フチ取り、吹き出し5種、しっぽ8方向、回転
  - 文字の大きさと吹き出しの大きさは別々。「文字を吹き出しにぴったり」「吹き出しを文字に合わせる」ボタン
  - 設定画面でいつも見えるのは 入力・大きさ・吹き出し・しっぽ。フォント／縦書き・フチ／色／回転／ページ移動／複製・削除 は引き出し式
  - 新しいセリフはページごとの「セリフ」レイヤー1枚にまとまる（一番上に作られる）
  - ページ移動：ボタン、または別ページの上までドラッグして離す（画面端で自動スクロール）。古い文字レイヤーも移せる
- 写真：コマ枠、左右反転、回転、横幅いっぱい、自由な切り取り
- 写真の棚：道具バーの上（たためる）、上にスワイプで貼る、アルバム切替、読み込み
- 素材：コマ割り7種（絵・写真より上、セリフより下に入り、コマの外を用紙の色で隠す）、集中線、スピード線
- 上の帯・道具の帯・写真の棚はたたむボタン付き
- 作品ごとの非表示＋全作品共通のパスワード（マイギャラリーで設定・変更。アプリを閉じると鍵がかかる。「忘れたとき」を2回押すとパスワードを消して全作品を表示に戻す）
- ひとつ戻す・やり直し、PNG書き出し、オフライン起動

## 決まったこと
- 作業はiPadだけ、主に縦向き。名前「タテ読み漫画工房」、アイコンはペンの絵（どちらも仮）
- 吹き出しへの文字の自動合わせはやめ、ボタンで合わせる
- フォント一覧も引き出しに入れる（仮）
- 非表示は「見えなくする鍵」で暗号化はしない。作品の削除にパスワードは不要
- 前に作った作品の文字は別々のレイヤーのまま。古いコマ枠（一番下）もそのまま。必要なら入れ直す
- 用紙の色を変えても、コマの外の色は追加したときの色のまま（仮）
